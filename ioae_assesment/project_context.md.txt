# Project Context: LMN Uncertainty Indices for the Mexican Economy

## Research Goal

Applying the **Growth at Risk (GaR)** methodology (Adrian, Grinberg, Liang, Malik & Yu, 2019) to Mexico. The key input is a financial conditions index analogous to the NFCI used in the original paper. After reviewing available options for Mexico (IMF FCI, ICF from *El Trimestre Económico*, Banxico FAVAR-based FCI), the project pivoted to constructing **structural uncertainty indices** following the **Ludvigson, Ma & Ng (2021) — LMN** methodology, which decomposes uncertainty into a **Macro Uncertainty index (MU)** and a **Financial Uncertainty index (FU)** and identifies their causal direction via a proxy SVAR.

## Uncertainty Measures — Conceptual Background

Four distinct uncertainty measures were discussed and contrasted:

| Measure | Core question | Method | Conflates with risk aversion? |
|---|---|---|---|
| **VIX** | How much do markets expect asset prices to fluctuate? | Options-implied vol | Yes |
| **EPU** | How uncertain is the policy environment? | Newspaper text + surveys | Partially |
| **JLN** | How unpredictable is the macroeconomy broadly? | Large factor model + GARCH | No |
| **LMN** | Which uncertainty — macro or financial — is causal? | JLN + proxy SVAR | No |

**JLN key insight:** uncertainty = conditional volatility of the *unforecastable* component of a variable, after projecting out all common predictable variation via a factor model. This strips forecastable volatility that VIX and EPU retain.

**LMN key insight:** extends JLN by separating MU and FU and identifying causal direction. Macro uncertainty shocks cause output declines; financial uncertainty is largely endogenous to real conditions.

## Methodological Decisions Made

### 1. Treatment of Non-Traditional Variables — Option B

Non-traditional variables (Google Trends, mobility, satellite data) **enter the factor extraction step** but are **excluded from MU and FU aggregation**. This improves factor precision without contaminating the economic interpretation of the uncertainty indices.

Three options were considered:

| Option | Factor extraction | Uncertainty aggregation |
|---|---|---|
| A — Drop | Excluded | Excluded |
| **B — Factors only** *(chosen)* | **Included** | **Excluded from MU/FU** |
| C — Third index (NTU) | Included | Separate NTU index |

External (US) variables are assigned to **MU**.

### 2. Transformation Strategy

Adopted directly from Corona et al. `01_preparing.R`:

- Seasonal adjustment via `seas()` for flagged variables (SA == 1 in catalog)
- `cpm(x, d)`: log-difference growth rates — `d=1` monthly, `d=12` annual
- `best_trans(y, x, names_y, names_x, rel)`: picks the transformation
  (linear / monthly / annual) that maximises correlation with IGAE growth,
  subject to a sign constraint `rel ∈ {I, P, N}` read from `Catalogo.csv`

| `rel` value | Selection rule | Typical variables |
|---|---|---|
| `"I"` | `max(abs(rho))` — sign-indifferent | Interest rates, exchange rate |
| `"P"` | `max(rho)` — positive correlation | Employment, production |
| `"N"` | `min(rho)` — negative correlation | Unemployment rate |

**Key bug fix:** `names(igae_mv) <- dates_dfm[-1]` required immediately after
computing `igae_mv <- cpm(igae_raw)`, because `cpm()` returns a vector of
length `n - 1` with no names. Without this, `l[names_y]` inside `best_trans()`
returns a zero-length vector and `cor()` throws an incompatible dimensions error.

### 3. Factor Extraction

Adopted from Corona et al. `02_models.R`:

```r
nowcast(YFCST ~., method = "2s", r = rhat, p = 1, q = rhat)
```

from the `nowcasting` package.

**Installation:** `nowcasting` removed from CRAN 2022-05-25 (depends on
archived `matlab` package). Install via:

```r
install.packages(
  "https://cran.r-project.org/src/contrib/Archive/matlab/matlab_1.0.2.tar.gz",
  repos = NULL, type = "source"
)
remotes::install_github("nmecsys/nowcasting")
```

**Key bug fix** — `'ts' object must have one or more observations` error:
`nowcast()` with `method = "2s"` requires at least one trailing `NA` on `YFCST`
to define a prediction period. Fix: append one `NA` to `YFCST` and one `NA` row
to the predictor matrix before calling `nowcast()`, then trim the extra row from
`fhat_` afterwards:

```r
yfcst_in <- c(igae_mv[13:length(igae_mv)], NA)
X_ext    <- rbind(X_scaled, matrix(NA, nrow = 1, ncol = ncol(X_scaled)))
# ... build db_now, call nowcast() ...
fhat_    <- fhat_full[1:(nrow(fhat_full) - 1), , drop = FALSE]
e_idio   <- X_scaled - fhat_ %*% t(Phat_)   # use X_scaled without extra row
```

### 4. Factor Count Selection

| Criterion | Selection | Notes |
|---|---|---|
| Bai-Ng IC1 / IC2 / IC3 | **r = 8** (unanimous) | All three agree — no ambiguity |
| Onatski (2010) ED | **r = 3** | `betahat = 0.9506` |
| Scree elbow | r = 3 visually | Sharp drop after factor 3 |
| Variance at r = 3 | 73.2% | Leaves 26.8% idiosyncratic |
| Variance at r = 8 | 89.8% | Leaves 10.2% idiosyncratic |

**Bai-Ng IC table interpretation:**

```
k=1: -0.454   Δ = -0.446  ← large
k=2: -0.709   Δ = -0.255  ← large
k=3: -0.962   Δ = -0.252  ← large
──────────────────── elbow
k=4: -1.028   Δ = -0.066  ← drops to <1/3
...
k=8: -1.237   ← minimum (Bai-Ng selection)
```

**Why they disagree:** Bai-Ng assumes *pervasive* factors (loading on all
variables); Onatski uses random matrix theory and is robust to *weak* factors.
Factors 4–8 are likely block-specific (loading within one variable group) —
strong enough for Bai-Ng but below Onatski's eigenvalue noise threshold.

**Decision:** use `r = 8` (Bai-Ng) as **baseline** — all three IC criteria
agree and block-specific financial/external factors are economically meaningful
in the LMN context. Run `r = 3` (Onatski) as **robustness check**. If
correlation between MU$_{r=8}$ and MU$_{r=3}$ exceeds 0.85 the choice of r
is not driving results.

## Pipeline Architecture

```
01_preparing.R logic
│
├── Load Datos.csv + Catalogo.csv
├── Filter active variables (cat_dfm[, "IGAE"] == 1)
├── Seasonal adjustment (seas())
├── best_trans() loop → db_dfm_trans   (stationary panel, T × N)
│
02_models.R logic
│
├── scale(db_dfm_trans) → X_scaled
├── bai_ng(X_scaled, demean = 2) → rhat = 8
├── nowcast(method = "2s") → fhat_ (T × 8), Phat_ (N × 8)
├── e_idio = X_scaled − fhat_ %*% t(Phat_)            [T × N]
│
LMN additions
│
├── fit_garch11(e_idio[, i]) for each variable → sigma_mat  [T × N]
├── MU = rowMeans(sigma_mat[, MACRO_VARS])      [standardised]
├── FU = rowMeans(sigma_mat[, FINANCIAL_VARS])  [standardised]
│
└── Proxy SVAR: VAR([MU, FU, IGAE_growth])
    ├── Lag order: SC criterion (capped at 4)
    ├── Ordering A: MU → FU → IGAE   (LMN baseline)
    ├── Ordering B: FU → MU → IGAE   (alternative)
    ├── IRFs with 90% bootstrap bands (500 replications)
    └── FEVD at 12-month horizon
```
